Slot 1 (ISA) VGA card

Cards change only with the power off; the monitor and the keyboard can be plugged in and out while the machine runs. On the board: 8086 CPU, 640 KB, interrupt controller, timer, keyboard controller and speaker. There is no disk yet, so the program is loaded straight into memory. The machine sees a US keyboard; touch screens have no physical keys to send.
