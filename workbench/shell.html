Slot 1 (ISA) VGA card
Slot 2 (ISA) drive A: on its cable Diskette adapter

Cards change only with the power off; the monitor and the keyboard can be plugged in and out while the machine runs. On the board: 8086 CPU, 640 KB, interrupt controller, timer, DMA controller, keyboard controller and speaker. Run loads a .COM program straight into memory; at power on the BIOS boots the diskette in drive A:. The machine sees a US keyboard; touch screens have no physical keys to send.

NASM syntax for the 8086, assembled as a .COM program at org 100h; a program at org 7C00h is a boot sector, and Run writes it to the diskette and boots. Ctrl+Enter runs it. Text in strings is stored as code page 437.
